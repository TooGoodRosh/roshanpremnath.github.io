Project Highlight: Behavioural System Design
All creature behaviour is driven by a context-based state machine. The system is fully deterministic: same context, same output, every time. The player's power to manipulate the ecosystem depends entirely on this predictability.
01
Detection Radius
A circular physics body centred on the creature. Broadcasts the type of every entity inside it (player, creature, fruit, or corpse) to the State Decider.
02
State Decider
The priority engine. When multiple conditions are active simultaneously, it evaluates all of them against the creature's priority list and returns the highest-ranked state.
03
State Manager
Holds the current active state. Switches immediately when the Decider returns a different state. Activates the correct Behaviour Node and deactivates all others.
04
Behaviour Node
One script node per state. Runs its logic loop until the State Manager deactivates it or the task completes, then notifies the Manager to re-evaluate.
